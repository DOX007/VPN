Gratis VPN med Cloudflare WARP

Cloudflare WARP är en gratis klient som krypterar all trafik från din enhet via Cloudflares nätverk (WireGuard-baserat protokoll). Ingen server eller konto behövs.

1. Installera appen

iOS
Android
Windows
macOS
Linux

2. Aktivera

  1. Öppna appen och godkänn villkoren.
  2. Slå på reglaget så att läget är WARP.
  3. Kontrollera anslutningen nedan.

Ej kontrollerad.

Linux via terminal

warp-cli registration new
warp-cli connect
warp-cli status

Begränsningar

  • WARP ändrar inte ditt land. Du kan inte välja serverplats, så det går inte att kringgå geoblockering.
  • Trafiken går via Cloudflare, som alltså ser den. Använd det inte för att dölja identitet.
  • Gratisversionen har ingen garanterad hastighet. WARP+ är en betaltjänst.

Kontrollen använder https://www.cloudflare.com/cdn-cgi/trace och skickar ingen data till något annat än Cloudflare.
